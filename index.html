DEFI TOOL · CASH-AND-CARRY ARBITRAGE LIVE WEB APPLICATION

DeltaPerp Arbitrage Terminal

A web application that calculates net cash-and-carry yields between perpetual futures and spot markets, helping traders identify funding rate spreads with deterministic math instead of imprecise estimates.

What It Does & The Problem

Perpetual funding rates fluctuate continuously across DEXes like Hyperliquid and CEXes like Binance. Manually computing annualized returns while factoring in borrow fees, basis convergence, and trading slippage is slow and prone to calculation error.

What I Built & Implemented

Engineered an automated basis scanner calculating annualized net cash-and-carry yields, incorporating borrowing cost friction and step-by-step delta-neutral execution playbooks.

What Works Today

Live funding rate comparisons, deterministic APY math based on current orderbooks, and structured delta-neutral execution plans.

What Remains Experimental

Autonomous multi-venue trade execution and auto-rebalancing smart contracts (trades currently require manual user execution).
